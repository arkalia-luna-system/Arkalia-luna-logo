## 🎯 ARKALIA-LUNA (Projet Principal)

### **Description**

Générateur de logos techno-mystiques avec variantes émotionnelles pour le projet principal Arkalia-LUNA.

### **Fonctionnalités**

- ✅ **11 Styles** : Default, Ultimate, AI-Moon, Dashboard, Advanced, Simple-Advanced, Ultra-Max, Realism Max, Cosmic, AI, Hyper-AI
- ✅ **10 Variantes Émotionnelles** : Sérénité, Puissance, Mystère, Éveil, Créative, Pluie, Orage, Explosif, Ensoleillé, Neige
- ✅ **Génération Multi-format** : SVG, PNG, favicons
- ✅ **API REST** : FastAPI avec documentation Swagger
- ✅ **CLI Complet** : Interface en ligne de commande professionnelle

### **Éléments Visuels Générés**

- Logos principaux (mark_only, vertical, horizontal)
- Favicons (multi-tailles)
- App icons (512×512, 1024×1024)
- Bannières GitHub
- Assets Play Store (pour Arkalia CIA)

## 🤖 BBIA (Reachy Mini)

### **Description**

Générateur de logos BBIA pour le robot Reachy Mini avec support des formats officiels.

### **Fonctionnalités**

- ✅ **3 Formats** : mark_only, vertical, horizontal
- ✅ **Génération Multi-format** : SVG, PNG
- ✅ **Tailles Multiples** : 32, 512, 1024
- ✅ **Palette Officielle** : Couleurs BBIA (#008181, #FFFFFF, #CCCCCC)
- ✅ **CLI Intégré** : Commandes `bbia` et `bbia-all`

### **Éléments Visuels Générés**

- Logos BBIA (3 formats × 3 tailles = 9 logos de base)
- Support futur : Variantes émotionnelles (10 variantes)

## 🎯 UTILISATION

### **Générer des logos Arkalia-LUNA**

```bash
# Logo Ultimate en variante Sérénité
python -m src.cli generate -v serenity -s 200 -g ultimate

# Tous les logos
python -m src.cli generate-all -s 200
```

### **Générer des logos BBIA**

```bash
# Logo BBIA mark_only
python -m src.cli bbia --variant mark_only --size 512

# Tous les logos BBIA
python -m src.cli bbia-all
```

### **Générer des logos Quest** (à venir)

```bash
# Logo Quest en variante Sérénité
python -m src.cli quest -v serenity -s 200

# Tous les logos Quest
python -m src.cli quest-all

# Bannières Quest
python -m src.cli quest-banners

# Badges Quest
python -m src.cli quest-badges --type mission
```
